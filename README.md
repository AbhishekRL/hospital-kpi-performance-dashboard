# 🏥 Hospital KPI Performance Dashboard

**Healthcare Analytics | Microsoft Power BI | HMIS**

## 📊 Project Overview

The Hospital KPI Performance Dashboard is an interactive healthcare analytics dashboard developed using Microsoft Power BI.

It provides a consolidated view of key hospital performance indicators across HMIS, OPD, IPD, ABHA, Laboratory, and Pharmacy modules.

The dashboard helps monitor hospital performance, analyze service utilization, and support data-driven decision-making.

## 🎯 Key Features

- **OPD Analytics:** Monitor total OPD appointments, BPL OPD, and APL OPD.
- **ABHA Analytics:** Track OPD ABHA generation and linking.
- **IPD Analytics:** Monitor inpatient department performance.
- **Laboratory Analytics:** Track laboratory-related performance indicators.
- **Pharmacy Analytics:** Monitor pharmacy-related performance indicators.
- **Facility Filter:** Analyze performance across different healthcare facilities.
- **Date Range Filter:** View KPI performance for selected periods.
